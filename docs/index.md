# AeroBeat Web Docs

AeroBeat Web is the browser-native product direction for AeroBeat. It uses JavaScript, JSDoc, HTML, CSS, native Web Components, Web Audio, WebGL-based rendering through PlayCanvas, and browser camera/CV APIs.

These docs publish accepted web architecture rules for contributors. The active orchestration plan remains the detailed work record; this site keeps the stable public summary.

## Start Here

- [Web Polyrepo Architecture](architecture/web-polyrepo-architecture.md) summarizes the accepted repo boundaries, package naming, code posture, component rules, and release posture.
- [Web Repo Map](contributors/web-repo-map.md) tells contributors where work belongs across the current web repo family: built implementation repos, vendor adapter repos, and planned domains.
- [Secure Testbed Serving](architecture/secure-testbed-serving.md) explains the early HTTPS/Tailscale expectations for camera and browser scene validation.
- [Documentation Handoff](contributors/documentation-handoff.md) explains when repo-local notes should be mirrored here.

## Scope

`aerobeat-web-docs` covers web-specific architecture and contributor documentation for the `aerobeat-web-*` family. Broader product, licensing, legacy Godot-era, and general design documentation continues in `aerobeat-docs`.
